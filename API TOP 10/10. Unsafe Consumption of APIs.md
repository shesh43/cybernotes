# API10 Unsafe Consumption of APIs 
## **Unsafe API Consumption:** _Trust external API data without proper validation._ 
This happens when an application blindly trusts or improperly handles data received from another API.

### Impacts
Unsafe API Consumption → Compromise through untrusted API data
1. Attacker-controlled data can affect your application.
2. Data leakage or manipulation.
3. Compromise of application functionality through a trusted API.

### How to Test 

I test for Unsafe Consumption of APIs by identifying third-party or internal APIs that the application trusts, and then checking whether it properly validates, authenticates, authorizes, and handles the data received from those APIs.

I would check:

- Whether the application **trusts API responses without proper validation**
- Improper handling of **malformed or unexpected responses**
- Weak authentication when communicating with external APIs
- Missing **TLS/certificate validation**
- Excessive trust in data received from third-party APIs
- Lack of **timeouts, rate limits, or response-size limits**
- Whether sensitive data from an external API is unnecessarily exposed
- Whether an attacker could manipulate a consumed API and influence application behavior

**Example:**

Suppose an application retrieves a user's shipping information from a third-party API:
```
GET /api/shipping-details/123
```
If the application blindly trusts the external API's response and uses attacker-controlled fields without validation, I would test whether those values can cause unintended behavior in the application.

**Key distinction:**

**Unrestricted Resource Consumption** focuses on exhausting _your application's resources_.

**Unsafe Consumption of APIs** focuses on _your application improperly trusting or handling data/services from another API_.

I identify APIs consumed by the application and verify that their responses, authentication, transport security, error handling, and resource usage are properly validated rather than blindly trusted.

### How to prevent 
Unsafe API consumption → Don't blindly trust external APIs
1. **Validate and sanitize data** received from external APIs.
2. Use secure authentication and TLS when communicating with them.
3. Apply timeouts, rate limits, and response-size limits.
